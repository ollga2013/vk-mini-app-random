# Подведение итогов VK

Мини-приложение для подведения итогов конкурсов во ВКонтакте.

## Что умеет

- импорт участников из VK API
- фильтры по репосту, комментарию и лайку
- выбор нескольких победителей
- антифрод-проверки
- экспорт результатов в `TXT`, `JSON` и `PNG`

## Запуск

```powershell
node server.js
```

Открыть:

```text
http://localhost:4173
```

## Переменные окружения

Нужны токены VK на сервере:

```powershell
$env:VK_USER_TOKEN="..."
$env:VK_SERVICE_TOKEN="..."
$env:VK_API_VERSION="5.199"
$env:VK_IMPORT_SCAN_DEPTH="60"
```

Или заполни `.env.local`.

## Важно

- токены не должны уходить в браузер
- живой импорт работает через локальный `/api/import`
- для PNG-экспорта аватары проксируются через `/api/image`
